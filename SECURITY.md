# Security

Navi handles potentially sensitive local task evidence and can perform explicitly confirmed text-file
rollback. It is experimental and does not claim a hardened security boundary around the executing agent.

Please do not put credentials, private code, conversation logs or exploitable details in a public issue.
Use GitHub private vulnerability reporting if it is available for this repository. Otherwise open a
minimal issue requesting a private reporting channel, without sensitive details.

Only the current development version is maintained. Reports involving incorrect authorization,
rollback boundaries, path traversal, prompt injection, data leakage or provenance validation are relevant.
Include a synthetic reproduction, version, platform and expected/actual behavior when possible.
